# UBPhD-Curriculum-Vitae2026

Repositorio correspondiente a la actividad de hoja de vida en HTML.

## Archivos

- `index.html`: contenido principal de la hoja de vida.
- `styles.css`: estilos visuales del sitio.

## Visualización

El proyecto puede publicarse mediante GitHub Pages desde la configuración del repositorio:

`Settings` → `Pages` → `Deploy from a branch` → rama `main` → carpeta `/root`.

Luego GitHub generará una URL pública para visualizar la hoja de vida como sitio web.
